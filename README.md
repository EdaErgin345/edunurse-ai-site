# EduNurse AI

Hemşirelik öğrencileri ve eğitimcileri için yapay zeka platformu: yazılar, araştırmalar, kongre takvimi ve sınıfta kullanılabilecek araçlar (Bakım Planı Aracı, Sanal Hasta, Uygulama Dosyası).

Sunucu tarafında çalışan kodu olmayan, statik bir web sitesidir. Netlify üzerinden yayınlanır.
